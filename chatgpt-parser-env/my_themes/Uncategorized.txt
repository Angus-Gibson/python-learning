- **Appeal:** If the case proceeds and the judge refuses to recuse, a higher court can be asked to overturn decisions, order a new trial, or assign a different judge. A clear record of bias makes for strong grounds on appeal.  
- **Motion to Vacate/Set Aside Judgment:** If the case already concluded, attorneys could argue the judgment is invalid due to judicial bias.

- **Judicial Conduct Complaint:** Lawyers can file a formal complaint with the state’s judicial conduct commission (or the federal circuit’s judicial council if it’s a federal judge). Such remarks are serious violations of the judicial code of ethics.

### **Professional Responsibility Angle**
Lawyers have an ethical duty (under ABA Model Rule 8.3 and similar state rules) to report judicial misconduct of this severity. They can’t just ignore it, even if it doesn’t directly hurt their own case.

Then you said:

> When it is called, the interpreter resolves its scope via LEGB…

Tiny refinement here.

LEGB isn’t resolved *when the function is called* in the way people often think.

Here’s the more precise version:

- **When a function is defined**, it captures references to variables in its enclosing scope. That’s how closures form.
- **When a function is called**, Python creates a new stack frame.
- Variable lookup inside that frame follows LEGB *at runtime*.

That nuance matters.

---

Let’s tighten the execution sequence:

### 🔁 What Actually Happens When You Call a Function

1. Python evaluates the function object reference.
2. It evaluates arguments first.
3. It creates a new stack frame.
   - Local variables live here.
   - Arguments are bound to parameter names.
4. It links that frame to:
   - The calling frame
   - The global namespace
   - The built-in namespace
5. Bytecode executes inside that frame.
6. If a `return` is hit:
   - The return value is passed back to the caller.
   - The frame is popped off the call stack.
7. If no return:
   - `None` is returned implicitly.

The frame disappears once no references to it remain.

That “popping the stack” is literal.
